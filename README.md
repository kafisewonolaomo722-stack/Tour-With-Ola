# Tour with Ola

Tourism website for Badagry, Lagos State, Nigeria: attractions, museums, local and international ticket requests, and contact.

Contact: kafisewonolaomo722@gmail.com

## Pages
index.html, attractions.html, museums.html, tickets.html, about.html, contact.html (plus 404.html)

## Deploy on GitHub Pages
1. Create a free account at github.com and click **New repository**. Name it `tour-with-ola` (Public).
2. Click **uploading an existing file**, drag in **everything inside this folder** (index.html must be at the top level, not inside another folder), and click **Commit changes**.
3. Open **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, Folder **/ (root)**, then Save.
4. Wait 1-2 minutes. Your site is live at `https://YOUR-USERNAME.github.io/tour-with-ola/`.

## Add real photos
Put your own (or properly licensed) photos in the `img` folder with these exact names, JPG, about 1600 px wide, under 400 KB:
point-of-no-return.jpg, slave-relics-museum.jpg, heritage-museum.jpg, first-storey-building.jpg, seriki-abass-barracoon.jpg, agia-tree.jpg

Until a photo is added, the site shows a labelled placeholder.

## Edit prices
Open `tickets.html` and change the prices in the table and in the dropdown list. The prices in this version are sample figures.

## Notes
Ticket requests open the visitor's email app with a pre-filled message to the address above. There is no online payment in this version.
